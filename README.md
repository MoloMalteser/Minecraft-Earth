# 🌍 Minecraft Earth Revival

A **fan project built in Godot Engine** that aims to bring back the spirit of the discontinued game **Minecraft Earth**.  
The goal is to recreate and expand the original idea for modern devices – with custom technology, new features, and an active community.

---

## 🚀 Features (planned / in progress)
- ✔️ Basic building system
- ✔️ UI
- ✔️ Block and item management  
- ⏳ Multiplayer (local & online planned)  
- ⏳ Adventure mode with quests  
- ⏳ AR integration (experimental)
- ⏳ Textures

---

## 🛠️ Technology
- Engine: [Godot 4](https://godotengine.org/)  
- Language: GDScript (partially C# planned)  
- Platforms: Android as an Apk and iOS possibly for self Build :( I have no Mac
